# Changelog

All notable changes to **MailForge** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- Personalised emails from a contacts CSV and one Jinja2 HTML template, subject included
- `--dry-run` that writes every rendered email to its own preview file
- Real SMTP sending with STARTTLS and login, as `multipart/alternative` (plain text + HTML)
- Rate limiting with `--rate` (`N/sec`, `N/min`, `N/hour`)
- One retry per contact and a dated audit log of every attempt
- Next.js project page
